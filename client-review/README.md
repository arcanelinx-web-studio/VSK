# VSK interactive website direction review

This folder is the client-facing design chooser. It is intentionally separate from the production website and does not deploy anything.

## Experience

Open `index.html` and choose one of three interactive directions:

- **A — Engineered / Editorial**
- **B — Cinematic Machine Showcase**
- **C — Precision / European Industrial**

Each option can be scrolled and interacted with like a real website. The floating A/B/C switcher allows direct comparison without returning to the chooser first.

## Brand and imagery rules

- The logo shown throughout the review is `../media/brand/vsk-logo.webp`, generated from the supplied `assets-source/VSK LOGO.png`; it is not a generated or redesigned logo.
- Option B uses VSK project media from the supplied archive, including the Kellenberg retrofit, servo seal slotting machine, Z-cut machine, air-leak testing machine and U-drill references. It does not use a generic CNC-spindle hero.
- All three options use VSK project imagery rather than stock industrial photography.

## Review purpose

The client is choosing the **visual direction**, not approving final copy, final section order, hosting or domain configuration. After the client selects A, B or C, only that direction will be developed into the final website.

# VSK Electro-Mech Solutions — Website Design Options

This review is for choosing the website direction before any hosting, domain or deployment decision.

## Interactive client chooser

Use `client-review/index.html` as the primary client-review experience. It opens with three selectable concepts and lets the client scroll and interact with each option like a real website, then switch directly between A, B and C.

The review pack uses the actual VSK brand asset through `media/brand/vsk-logo.webp`, which is generated from the supplied `assets-source/VSK LOGO.png`. The client-review concepts do not use a generated/reinterpreted VSK logo.

Option B also uses VSK's own project photography and footage rather than a generic CNC spindle/machining image. Its visual story is built from the VSK Kellenberg retrofit, servo seal slotting machine, Z-cut machine, air-leak testing machine and U-drill references.

## Option A — Engineered / Editorial

**Positioning:** Integrated engineering partner.

**Visual language:** Dark technical hero, VSK octagonal geometry, interactive capability tabs, project archive, strong proof metrics and structured engineering enquiry.

**Best for:** A client who wants the website to communicate breadth of engineering capability and look modern and technical without becoming overly cinematic.

**Primary impression:** `Engineering depth + integrated capability + modern industrial brand`

---

## Option B — Cinematic Machine Showcase

**Positioning:** The machines are the brand.

**Visual language:** Full-screen VSK project footage, dramatic typography, large BUILD / REVIVE / MAKE chapters, large-format real project photography and minimal UI chrome.

**Best for:** A client who wants a memorable, premium, machine-first website with the strongest visual impact.

**Primary impression:** `Premium + visual + bold + machine-first`

---

## Option C — Precision / European Industrial

**Positioning:** Precision engineering organization.

**Visual language:** Light background, strict grid, precise typography, technical register rows, specification-style project presentation, restrained motion, thin-line detailing and measured blue accents.

**Best for:** A client who wants a highly professional, clean, European/German/Swiss industrial feel with less visual drama and more engineering discipline.

**Primary impression:** `Precision + trust + sophistication + corporate engineering`

---

## What stays consistent in all three

- Actual supplied VSK logo and two-blue brand identity
- Real VSK machine/project photography
- VSK machine-building, retrofit/reconditioning and precision-manufacturing positioning
- Project proof points such as 20 µm, 0.02 mm and 12 sec where used
- Google review/social-proof direction
- Direct phone, email and WhatsApp enquiry paths
- Responsive behavior and reduced-motion support
- No stock or AI-generated machine photography in the interactive review

## Client decision question

**Which direction best represents how you want VSK Electro-Mech Solutions to be perceived?**

- **A — Engineered / Editorial**
- **B — Cinematic Machine Showcase**
- **C — Precision / European Industrial**

The selected direction will then be refined into the final website. Content, section order, imagery and animation can still be adjusted after the visual direction is chosen.
